# 🐸 TerraPi

### A tiny terrarium monitor for Raspberry Pi and Sense HAT

TerraPi is a work-in-progress Python project for displaying terrarium temperature on a Raspberry Pi with a Sense HAT. It can report temperatures in Celsius or Fahrenheit and includes a Pacman frog-inspired display mode.

> **Status:** Under active development. The configuration and startup flow are still being refined.

## ✨ What’s inside

- 🌡️ Read the temperature from the Sense HAT
- 🌍 Display temperatures in Celsius or Fahrenheit

## 🧰 What you’ll need

- A Raspberry Pi # Made for a Raspberry pi 4
- A Sense HAT
- Python 3 and the Type `sudo apt install sense-hat` to install the sense-hat library on your Raspberry pi.

## 📁 Project files

| File | Purpose |
| --- | --- |
| `Main.py` | Main script: reads the temperature, selects the monitor mode.
| `Pacman.py` | Pacman frog monitor mode.
| `settings.ini` | Intended place for mode and display settings.

## 🚧 Coming together

TerraPi is still being built, so setup and configuration may change. The goal is to make it easy to monitor terrarium conditions at a glance—right on the Pi’s LED matrix.

## 🚧 What will be
There will be a room monitor setting. Cooler Art, joystick functions, Humidity.
